## 5.3 Core Analytics Metrics

---

### 1. Total Transaction Volume per User

**Purpose:**
- Measure user activity
- Identify high-value customers

---

#### SQL Query

```sql
SELECT 
    u.id AS user_id,
    u.name,
    COUNT(t.id) AS total_transactions,
    SUM(t.amount) AS total_volume
FROM Users u
JOIN Accounts a ON a.userid = u.id
JOIN Transactions t ON t.sourceaccountid = a.id
GROUP BY u.id, u.name
ORDER BY total_volume DESC;
````

---

#### Explanation

* Joins Users → Accounts → Transactions
* Counts transactions per user
* Sums transaction values
* Orders by highest activity

---

### 2. Monthly Transaction Trends

**Purpose:**

* Understand spending patterns over time
* Support trend visualization

---

#### SQL Query

```sql
SELECT 
    DATE_TRUNC('month', createdat) AS month,
    COUNT(id) AS total_transactions,
    SUM(amount) AS total_volume
FROM Transactions
GROUP BY month
ORDER BY month;
```

---

#### Explanation

* Groups transactions by month
* Aggregates count and total value
* Used for line or bar charts

---

### 3. Fraud Rate

**Purpose:**

* Measure system risk level
* Monitor fraud detection effectiveness

---

#### SQL Query

```sql
SELECT 
    COUNT(DISTINCT f.transactionid) * 100.0 / COUNT(t.id) AS fraud_rate_percentage
FROM Transactions t
LEFT JOIN FraudFlags f ON f.transactionid = t.id;
```

---

#### Explanation

* Counts total transactions
* Counts flagged transactions
* Calculates percentage

---

### 4. Top Risky Accounts

**Purpose:**

* Identify accounts with frequent fraud activity
* Assist fraud analysts

---

#### SQL Query

```sql
SELECT 
    a.id AS account_id,
    a.accountnumber,
    COUNT(f.id) AS fraud_count
FROM Accounts a
JOIN Transactions t ON t.sourceaccountid = a.id
JOIN FraudFlags f ON f.transactionid = t.id
GROUP BY a.id, a.accountnumber
ORDER BY fraud_count DESC
LIMIT 10;
```

---

#### Explanation

* Links accounts to flagged transactions
* Counts fraud occurrences
* Returns top risky accounts

## 5.5 Analytics Service Design

### Responsibilities

* Execute raw SQL queries
* Map results to DTOs
* Serve data to controllers

---

### Example (C#)

```csharp
public async Task<IEnumerable<UserTransactionSummary>> GetUserSummary()
{
    var query = @"SELECT u.id, u.name, COUNT(t.id), SUM(t.amount)
                  FROM Users u
                  JOIN Accounts a ON a.userid = u.id
                  JOIN Transactions t ON t.sourceaccountid = a.id
                  GROUP BY u.id, u.name";

    return await _context.Set<UserTransactionSummary>()
        .FromSqlRaw(query)
        .ToListAsync();
}
```

* Avoid unnecessary joins
