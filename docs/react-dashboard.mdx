# Phase 6: Dashboard Design

## 6.1 Overview

The dashboard provides a **visual representation of analytics data** generated by the backend.

**Purpose:**
- Make system data easy to understand
- Highlight key financial and fraud insights
- Demonstrate full-stack capability

**Design Principle:**
- Keep UI simple
- Focus on data clarity, not design complexity

---

## 6.2 Dashboard Scope

This is **not a full banking app UI**.

Only build a **single page dashboard**:

```

/dashboard

```

---

---

**Displayed Metrics:**
- Total Transactions
- Total Volume (ZAR)

**Data Source:**
- `/api/analytics/trends`

**Data Source:**

### Dashboard Page

```javascript id="dash01"
import { useEffect, useState } from "react";
import { getSummary, getTrends, getRiskyAccounts } from "../services/api";

const Dashboard = () => {
  const [summary, setSummary] = useState(null);
  const [trends, setTrends] = useState([]);
  const [riskyAccounts, setRiskyAccounts] = useState([]);

  useEffect(() => {
    const fetchData = async () => {
      const s = await getSummary();
      const t = await getTrends();
      const r = await getRiskyAccounts();

      setSummary(s);
      setTrends(t);
      setRiskyAccounts(r);
    };

    fetchData();
  }, []);

  return (
    <div>
      <h1>Dashboard</h1>

      {summary && (
        <div>
          <p>Total Transactions: {summary.totalTransactions}</p>
          <p>Total Volume: {summary.totalVolume}</p>
          <p>Fraud Rate: {summary.fraudRate}%</p>
        </div>
      )}

      <div>
        <h2>Trends</h2>
        {/* Chart goes here */}
      </div>

      <div>
        <h2>Risky Accounts</h2>
        <ul>
          {riskyAccounts.map((acc) => (
            <li key={acc.accountId}>
              {acc.accountNumber} - {acc.fraudCount}
            </li>
          ))}
        </ul>
      </div>
    </div>
  );
};

export default Dashboard;
```
